# Tweet-Code

A collaborative, mobile-first web application for developers to share and discuss coding solutions.

**Project type:** University of Utah coding bootcamp team project (five developers)

## Project overview

- React frontend with responsive layouts
- Node.js and Express backend
- GraphQL data access
- MongoDB with Mongoose
- JWT authentication
- Team collaboration using Git and GitHub

## My contribution

I worked on the frontend using React and contributed to GraphQL integration, authentication, and backend setup alongside four teammates. This was a **team project**, not a solo build.

## Running the project

This is an older educational project and may require dependency or configuration updates before running locally. A working public deployment has not been verified.
